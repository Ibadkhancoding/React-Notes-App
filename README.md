# React Notes App

A simple Notes App built with React. You can add notes, delete them, and keep them saved even after refreshing the page.

## Live Demo

[View Live Demo](YOUR_LIVE_DEMO_URL)

## What I Used

* React
* JavaScript
* Tailwind CSS
* Vite
* localStorage
* Lucide React

## What It Can Do

* Add notes
* Delete notes
* Save notes in localStorage
* Load saved notes after refresh
* Responsive design

## What I Practiced

This project helped me get better at:

* `useState`
* `useEffect`
* Props
* Components
* `map()` and `filter()`
* localStorage
* Responsive UI

## Run It Locally

```bash
git clone https://github.com/Ibadkhancoding/React-Notes-App.git
cd React-Notes-App
npm install
npm run dev
```
